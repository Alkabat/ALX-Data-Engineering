# Week 03 Notes

* Data Lake is a centralized storage facility for heterogeneous data at any scale.
* Data Warehouse is an organized data store for relational data.
* Schema-on-Write is associated with Data Warehouses while Schema-on-Read is associated with Data Lakes.
* The three main storage zones are Bronze, Silver and Gold, with Gold containing trusted business-ready data.
* Common network protocols include FTP, SFTP, FTPS, NFS and SMB.
* ETL pipelines extract data from source systems, transform it and load it into modern platforms.
* REST APIs enable communication between systems through HTTP requests.
* REST commonly uses GET, POST, PUT and DELETE methods.
* Docker allows applications to run consistently in isolated containers.
* Streaming enables data to be processed in near real time.
* Batch processing handles data in scheduled groups while streaming processes data continuously.
* Common streaming architectures include Lambda, Kappa and Microservices-based architectures.
* Apache Kafka acts as a message broker between producers and consumers using an append-only log.
* Message delivery guarantees include At-most-once, At-least-once and Exactly-once processing.
* Amazon MSK provides managed Apache Kafka services in the cloud.
* JSON and Apache Avro are common data serialization formats used in streaming systems.
