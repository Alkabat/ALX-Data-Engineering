# Week 03 Reflection

Week 3 was one of the most practical weeks of my Data Engineering journey so far. I moved beyond theoretical concepts and gained hands-on experience with Docker, APIs, Kafka and streaming data pipelines.

One of the most valuable lessons was understanding the difference between Data Lakes and Data Warehouses and how organizations structure data using Bronze, Silver and Gold layers. I also learned how ETL pipelines move data from source systems to analytical platforms.

A major achievement this week was successfully installing and configuring Docker. I enabled virtualization, installed WSL2, created my first Dockerfile and ran my first container. This helped me understand how containerization supports portability and consistency across environments.

I also explored REST APIs and learned how applications exchange data using GET, POST, PUT and DELETE methods. Using the AccuWeather API, I built a simple streaming pipeline and extracted data for further analysis.

Another highlight was learning Apache Kafka and event streaming. I built a simple Kafka application and gained an understanding of producers, consumers, append-only logs and message delivery guarantees.

The most challenging aspect was setting up the environment for Docker and Kafka, but working through the configuration process improved my troubleshooting skills.

Overall, this week strengthened my understanding of modern data engineering infrastructure and gave me practical experience with technologies that are widely used in real-world data platforms.
