# Week 03 – Big Data Fundamentals, Docker and Streaming

## Topics Covered

* Data Lakes and Data Warehouses
* Schema-on-Read vs Schema-on-Write
* Bronze, Silver and Gold Data Architecture
* ETL Pipelines
* Network Data Transfer Protocols
* REST APIs
* Docker and Containerization
* Batch and Stream Processing
* Apache Kafka
* Streaming Architectures
* Amazon MSK
* JSON and Apache Avro Schemas

## Practical Activities

* Installed and configured Docker Desktop
* Enabled virtualization and WSL2
* Created and ran a Docker container
* Built a simple Kafka streaming application
* Retrieved weather data through the AccuWeather API
* Exported streaming data into CSV and TXT formats
* Executed streaming workloads using Docker and VS Code

## Key Takeaway

Modern data engineering combines scalable storage, automated pipelines, containerized applications, and real-time streaming systems to deliver reliable data for business decision-making.
