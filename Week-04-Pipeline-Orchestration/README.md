## README

This week focused on building scalable and automated data pipelines. I learned how orchestration tools such as Apache Airflow manage the sequence, timing, monitoring, and execution of data-processing tasks.

I also explored the use of Docker containers to support scalable data processing and learned how different types of pipeline triggers—on-demand, scheduled, and event-based—can be used to automate workflows.

A major part of the week involved understanding scalability requirements and identifying the factors that influence a system’s ability to handle increasing workloads. I applied these concepts to an e-commerce case study involving database contention, delayed inventory updates, slow report generation, overselling, and challenges with adding new features.

The week concluded with an introduction to distributed computation and Apache Hadoop, including its core components: HDFS, MapReduce, and YARN.
